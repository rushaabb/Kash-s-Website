# Kashmira — Official Website

Official artist portfolio and web platform for **Kashmira** — vocalist, singer-songwriter, and frontwoman from Pune's independent music scene.

## 🎵 Features
- **Hero Section:** Original background visual with centered logo and direct social streaming links (Instagram, Apple Music, Spotify, YouTube).
- **About:** Comprehensive artist bio and official portrait.
- **Pinned Horizontal Releases:** Smooth interactive horizontal scroll scrubbing through official singles and EP (*Now Then*, *What Will Be*, *To Be Found*, *Canvas*, *Cut To The Chase*, *Break Through*).
- **Live Shows & Spotlight:** Dynamic tour calendar and featured Karaoke Nights card synced in real-time with the backend.
- **Music Classes & Voice Acting:** Professional inquiries and vocal training highlights.
- **Bands:** Official showcases for *Stardust Symphony* and *Nine Lives Club*.
- **Interactive Media Gallery:**
  - **Photos:** High-resolution photography with full-screen lightbox preview.
  - **Videos:** 11 live performances, acoustic sets, and session recordings with custom video previews and full-screen video player lightbox.
- **Work With Me:** Direct contact channels with one-touch phone and email links.
- **Admin Dashboard (`/admin`):** Secure password-protected administrative interface to manage upcoming live shows and customize the Karaoke Nights spotlight in real-time.

## 🛠 Tech Stack
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6+), Font Awesome 6
- **Backend:** Node.js, Express.js
- **Auth & Storage:** JWT, bcryptjs, JSON persistence

## 🚀 Getting Started

### 1. Install Dependencies
```bash
cd server
npm install
```

### 2. Start the Server
```bash
node server.js
```
The application will run locally at **`http://localhost:3000`**.

### 3. Admin Access
Visit **`http://localhost:3000/admin`** to log into the administrative management console.
